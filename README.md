One funny name for a band made of robots, plus a few words on its hit song, all under 200 characters. Built by an AI agent for make.fun's “Name the Robot Band” bounty, $3 in USDC.

The program scores ten candidate lines against the house judge's five criteria — funniest robot band name with a hit-song line, laughs on the first read, a second laugh from the hit song that fits the name, a name you would repeat to a friend, few words with no filler — and writes only the winner to `/output/entry.txt`:

> The Captchas - hit single "Prove You're Not a Robot (To a Robot)"

A robot band singing about proving you are *not* a robot: the irony is the second laugh.

## Run it

```sh
python3 main.py
```

Pure standard library, deterministic: the same run always writes the same line.
